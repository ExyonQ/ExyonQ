## Why this release

WordPress on ExyonQ could show the installer but browsers could not complete setup: `/wp-admin/css/*` and `/wp-admin/js/*` were forwarded to php-fpm and returned **403** (`security.limit_extensions`). The installer UI (styles and language-chooser JS) was broken.

## Shipped

1. Product version **0.4.13**.
2. FastCGI + htaccess: existing non-PHP files served as static; defense in FastCGI dispatch.
3. Security audit artifact: `docs/security/audit-v0.4.13.md`.
4. Stronger publish gate for WordPress: create admin account and log in (rule 134), not only reach `install.php`.
5. `rustls` 0.23.46 (RUSTSEC-2026-0346 Medium).
