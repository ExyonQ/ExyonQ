## Why this release

0.5.0 is the source that was already in this tree: route matching, rewrite captures, try_files, error pages, variables, and the operational surfaces listed in the changelog. The server image now starts and serves a default page. The WordPress image reaches the installer and accepts a new account.

## Shipped

1. Product version **0.5.0**.
2. Server image: Debian bookworm slim, glibc binaries, default page on port 8080.
3. WordPress image: PHP 8.4-FPM, SQLite, `.htaccess` the 0.5 compiler accepts.
4. Official modules accept the 0.5.x core line.
5. Linux amd64 and arm64 binaries on the GitHub release.

## Not claimed

- Phase 1 CLOSED
- A `:latest` tag
- That Wasmtime 49.0.2 is free of the component-model advisories reported by `cargo deny`
