# ExyonQ v0.4.4.1

Published release.

- GitHub Release: https://github.com/ExyonQ/ExyonQ/releases/tag/v0.4.4.1
- Image: `ghcr.io/exyonq/exyonq:0.4.4.1` (`linux/amd64` and `linux/arm64`)
- Binaries: `exyonq-linux-amd64.tar.gz` and `exyonq-linux-arm64.tar.gz`
- Contact: contact@exyonq.org
- Security: security@exyonq.org

The Cargo crate version stays `0.4.4` because Cargo rejects a fourth numeric component. The release tag, the image tag, and `product_version` are `0.4.4.1`.

The runtime image is scratch. `exyonq` and `exyonqctl` are static musl binaries. The image ships CA certificates and the example config, and it does not include the Debian package set from 0.4.4. Provenance is `mode=max` and an SPDX SBOM attestation is attached.

The example config field is `path`, not `metrics_path`. Metrics stay off unless `scrape_bearer_token` is set on a public listen address.
