## Shipped — F5 "Cache y entrega de contenido"

1. **NG-15** — Cache keys with vary/bypass semantics: equivalence classes, allowlisted query params, vary material in key.
2. **NG-16** — `stale-if-error` serving + purge by tag/URL/namespace via control plane.
3. **NG-17** — `expires`/`cache_headers` runtime application; `add_header` with inheritance and denylist.
4. **NG-18** — nginx body transforms: `gunzip` (bounded streaming decode), `sub_filter` (chunk-boundary, MIME-scoped), `mirror` (background subrequests, `mirror_request_body` on/off, recursion-safe), `slice` (range-keyed segment cache with upstream range requests).
5. **OL-01/02** — OpenLiteSpeed parity: private-cookie cache denial (session cookies never stored) + nonce-safe FPC hard-deny prefixes with lint warning on oversized TTL+stale windows.
6. **Q-15** — `exyonq_http_request_duration_seconds{,_by_route}` histograms with bounded 64-series cardinality and dropped counters.
7. **ACME HTTP-01 across processes** (ADR-066) — filesystem-shared challenge store (`EXYONQ_ACME_CHALLENGE_DIR`) so multi-process deployments (redirect process + TLS process) can validate HTTP-01 without DNS API tokens. Atomic writes, token-name validation, `0600` files, graceful memory-only fallback.
8. **Q-10 (early)** — WAF metrics on `/metrics`: `exyonq_waf_{decisions,violations,inspections,inspection_seconds}` with per-rule top counts and 512-rule cap. Plus `exyonq_mirror_subrequests_total{outcome}` lifecycle counters.
9. **Early 0.9.1 surfaces** riding along: `auth_basic` (htpasswd verify), `zone_ratelimit` (nginx `limit_req_zone` token buckets per route), WAF body inspection scaffolding.
10. **NGINX static/`root`/`alias` semantics** — file-root exact match fixed (a `root` pointing at a file now serves it instead of producing a not-found join), `root_mode` chooses native-alias vs nginx-style full-URI join per route, exact-file `alias` parity, `alias` + `fastcgi_pass` dispatch, and the directory-redirect matrix (`absolute_redirect`, `port_in_redirect`, `server_name_in_redirect` equivalents) matching nginx including default-port elision on `:80`/`:443`.
11. **FastCGI front controller** (`front_controller = "index.php"` per route) — URIs that do not resolve to a regular file fall back to the named script under the document root with `PATH_INFO` set to the original path (NGINX `try_files $uri $uri/ /index.php?$args` parity; WordPress/Symfony/Laravel pattern). Missing scripts now return a real `404` and traversal a `403` instead of a blanket `502`. NGINX `try_files` with a PHP-shaped fallback maps to `front_controller` on import. See `docs/config/fastcgi.md`.
12. **Repeated `Cookie` headers preserved** — repeated `Cookie` request lines are merged with `"; "` (RFC 6265 §5.4 / RFC 7540 §8.1.2.5) in the reverse-proxy materialized, streaming, empty-body, WebSocket-upgrade, and spike paths and into FastCGI `HTTP_COOKIE`. Previously only the first or last line survived, which broke authenticated sessions for clients that fragment cookies (HTTP/2).
13. **`exyonqctl config lint|check|test --config <path>`** — the flag form is accepted alongside the positional path (`exyonq validate` parity); `config lint` also gains `EXY-LINT-0008` (`front_controller` set on a non-FastCGI route).

## Security fixes (this release)

- **Slice cache confidentiality** — segment store now applies the same response gates as the rest of the tree (no `Set-Cookie`/`private`/`no-store`/`Vary`/hop-by-hop 206s), stored headers filtered to the cache-safe allowlist, assembled responses strip `set-cookie` + hop-by-hop. Previously a 206 `Set-Cookie` could be replayed to anonymous clients.
- **Rate-limit memory exhaustion** — `zone_ratelimit` maps bounded per zone (entry cap + full-bucket eviction + key-byte cap); fail-open on poisoned mutex removed.
- **Unbounded buffers** — gunzip header state capped at 64 KiB; `sub_filter` drains before pulling more upstream frames; `WafBody` buffer capped at `max_bytes`; slice Passthrough `collect()` bounded to segment size.
- **Mirror suppression spoof** — `x-exyonq-mirror` is an internal marker now (request extension + header stripped at external entries); clients can no longer disable mirroring of their own requests.
- **WAF metric label injection** — `\n` escaped in `rule_id` labels.
- **wasmtime** bumped `=49.0.4` → `=49.0.5` clearing RUSTSEC-2026-0422/0423/0424 (dev-dependency only).
- **WordPress image PHP base** — moved from Wolfi `php-8.4` to the official `php:8.5.12-fpm-bookworm` build (PHP >= 8.5.12 policy; 8.5.12 fixes two unauthenticated RCE CVEs). glibc bookworm keeps the ExyonQ binary native; `intl`/`exif`/`gd`/`zip` compiled via `docker-php-ext-install`, build deps purged.
- **Importer honesty** — `sub_filter` replacements containing `$variables` now report `Unsupported` (nginx interpolates; ExyonQ emits literals).

## Known limitations

- `sub_filter` emits replacements literally (`$variables` not interpolated — importer reports `Unsupported`).
- FPC path bypass rules match raw paths (a `/%XX`-encoded path can evade an operator bypass rule; cookie-based protections unaffected).
- Slice segment entries are not addressable by purge tags/site; HEAD requests still assemble all segments (bounded at 64 MiB).
- Mirror `cancelled` outcome stays 0 — subrequests are detached, matching nginx fire-and-forget.
- NGINX differentials (deliberate, not parity bugs): ExyonQ redirects carry `Content-Length: 0` (nginx emits ~170 B HTML body); error pages are minimal (~9 B vs nginx's ~160-180 B); ExyonQ answers `403` where nginx would serve or normalize a `..`/symlink escape out of root (stricter, fails closed); `/%2e%2e/` decodes to `404` vs nginx `400`.
- FastCGI: `front_controller` covers the single-script pattern; NGINX `try_files` named locations (`@name`), `=code` fallbacks, and multi-candidate non-PHP chains remain Partial/Unsupported in the importer. Non-cookie repeated request headers (e.g. `Accept`, `Via`) are still collapsed to a single value on proxy materialization (cosmetic; `Cookie` is merged per RFC 6265).
- Full nginx compatibility is a continuing objective, not a claim of this release — the verified matrix covers the redirect/`root`/`alias`/FastCGI semantics above.
