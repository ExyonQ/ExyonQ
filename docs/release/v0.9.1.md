## Shipped

1. **AP-04 — external auth endpoint.** JWT/OAuth verification at an external
   endpoint, with original-request headers isolated from client-supplied
   copies. The documented pattern covers HS256 JWT, opaque bearer, upstream
   failure statuses and per-user `$remote_user`.
2. **OL-03 — per-client throttling.** The `perClientConnLimit` fields are
   migrated one-for-one and verified against a real OpenLiteSpeed 1.9.4
   oracle: soft grace, hard close, body truncation and the kernel connection
   lifecycle.
3. **OL-04 — challenge.** Native proof-of-work, reCAPTCHA and hCaptcha
   challenge paths, deployment configuration and a no-JavaScript fallback,
   including fail-closed rejection for invalid provider responses.
4. **OL-05 — OWASP CRS/ModSecurity.** Real CRS v4.25.0 corpus, block and
   detection-only differentials, 33 evidence-backed exclusions and per-rule
   Prometheus metrics. The dry-run and block passes now run in GitHub Actions.
5. **Release hardening.** `source_tag` is embedded in `--version` for tag
   traceability (EXY-14); the README no longer carries a release number; the
   server and WordPress images use Wolfi/Chainguard bases and are published
   with version-only tags.

## Known limitations

- **F6-WP-04 is still open:** its technical gate passed on the 0.9.0 tree, but
  the editorial/production closure and part of the F6 DoD are not closed. This
  release does not claim them.
- The WordPress production journey is still open: the 0.9.1 images are now
  published, but no authorized production copy was available to this checkout,
  so the real-browser login against production is still pending. The local
  installer HTTP check is not that E2E.
- The local image review is arm64. Final multiarch digest scans and native
  amd64/arm64 runtime checks are post-publication steps.
- The tag is annotated but **not signed**; no signature claim is made.
- No Windows build is produced, by policy.
- NGINX/Apache/OpenLiteSpeed compatibility remains the documented scope; this
  release does not claim total parity.
