**Security patch.** 0.9.3 ships `wasmtime` 51.0.0 (0.9.2 shipped 49.0.5), which includes the 49.0.6 bump that cleared RUSTSEC-2026-0566 through RUSTSEC-2026-0572; `cargo audit` reports no advisory and none is waived. Upgrade recommended from 0.9.2 or earlier.

## Changes

- **GeoIP (#112):** offline MMDB country policy — `[geoip]` table, `country:XX` access rules, `country` in access logs and WAF rules, `exyonqctl config geoip check --ip`.
- **ACME and HTTP/3 SNI:** each `[[server]]` block orders and renews its own certificate; the s2n HTTP/3 listener selects the certificate by client SNI.
- **FastCGI diagnostics:** pools are probed at startup and reload; failures name the pool, endpoint, `errno` and a PHP-FPM ownership hint instead of a bare `502`, and `exyonqctl fastcgi check --config <file>` reproduces the diagnosis offline.
- **WAF:** new `EXY-CMD-1003`–`1012` rules block Java/OGNL/Struts2 RCE probes, percent-encoded forms included; every 5xx emits one correlated `server error response` line.
- **Module body limit:** `[modules].response_body_limit_bytes` returns `413` for oversized unknown-length bodies instead of `500`.
- **Fixes:** exact routes outrank regex (#91) · `EXY-CONFIG-0016` for included routes no server lists (#90) · `protocol=https` in access events (#89) · `exyonqctl` exit codes 3/4 (#92) · packaged healthcheck finds the active `php*fpm*` unit (#81) · WAF violations carry site and request attribution (#84).
