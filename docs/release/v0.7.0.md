## Shipped — F3 "Borde y balanceo" (proxy/LB parity)

1. **NG-06** — PROXY protocol v1/v2 inbound; real client IP visible to logs/WAF/rate-limit behind HAProxy/ELB.
2. **NG-07** — Sticky sessions (cookie, source, header) + `leastconn`, consistent-hash, P2C selection policies.
3. **NG-08** — Upstream `backup` / `down` / `max_fails` / `max_conns` + extended `admin_state`; verified failover.
4. **NG-09** — Periodic upstream DNS re-resolution (`exyonq_upstream_dns_*` metrics); backend IP changes without reload.
5. **NG-10** — Active health checks with status/body/header expect rules, per-upstream intervals, passive circuit breaking.
6. **NG-11** — `set_real_ip_from` semantics: configurable trust for `X-Forwarded-For`; spoofing rejected by default.
7. **AP-01** — `BalancerMember` hot admin: `loadfactor`, `route`, `status` via `exyonqctl server set` without reload.
8. **F3-R20** — `ProxyPassReverse` / `proxy_redirect`: `Location`/`Content-Location`/`URI` response rewriting via `[[route.location_rewrite]]` in IR, Hyper + wire paths, authority-aware boundary matching (`/app` ≠ `/apple`), query/fragment preserved. Apache and NGINX importers + `migrate_to_exyonq.py` emit it.
9. **Cap067 static dataplane** — encoding cache (ADR-046) with gzip/brotli + quotas, warm-hit coded-FD cache, wire-cheap ratelimit+metrics without Hyper on all TCP paths, EPOLL keepalive pool geometry.
10. **WordPress image** — cache purge socket wired end-to-end (`EXYONQ_CACHE_PURGE_*` in `wp-config.php`); mu-plugin purges FPC on publish.
11. **Supply chain** — cargo-auditable SBOM embed, Rust 1.99.1, wasmtime 49.0.4; machete-clean dependency tree.
12. **Docker bases** — `gcr.io/distroless/cc-debian12:nonroot` (server, ~23 MB, no shell/pkg-manager, uid 65532) and `cgr.dev/chainguard/wolfi-base` + `php-8.4-fpm` (WordPress). Docker Scout: **0 critical / 0 high / 0 medium** on both images, both architectures.
