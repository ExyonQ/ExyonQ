## Why this release

0.6.0 is the public cut for **F2 operational confidence**: fail-closed htaccess diagnostics, cache observability (`X-Cache` + ctl), WebSocket reload/drain guarantees, config explain provenance, reload route diff, FCGI pool diagnostics, plus the Expires/`cache_headers` and `response_headers` transition work already present on the 0.5.x public tree. Product version advances from 0.5.0 so addon `core_compat` can cover `0.6.x`.
