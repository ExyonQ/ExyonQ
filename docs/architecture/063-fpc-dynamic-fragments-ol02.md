# ADR-063 — FPC and dynamic fragments: nonce-safe alternative to ESI (OL-02 / F5)

**Status:** Accepted
**Date:** 2026-10-27
**Depends on:** FPC WC2B/WC2C (`fpc_lookup` / `fpc_store`), NG-15 key/bypass, NG-16 stale-if-error, OL-01 private cookies
**Contract:** CONDITIONAL ACCEPT — cache anonymous WordPress pages with nonces; no ESI fragment inclusion

## Context

QUEJAS_OPENLITESPEED §2.7 / openlitespeed#372: a page cache without ESI makes WordPress nonces hard to cache. A cached page keeps one `wp_create_nonce()` value; if the entry outlives the nonce, forms and REST calls fail with `-1` / 403.

ExyonQ F5 (v0.9.0) has to answer OL-02: *fragment inclusion with per-fragment TTL **or** a documented and verified alternative*.

## Decision

**No ESI in F5.** ExyonQ adopts a **nonce-safe FPC** model built from the existing gates:

| Layer | Rule | Where |
| --- | --- | --- |
| Request | Logged-in / session cookies bypass FPC (`wordpress_logged_in_*`, `wordpress_sec_*`, `wordpress_*`, `wp-settings-*`, `wp-postpass_*`, `comment_author*`, WooCommerce session/cart, `PHPSESSID`) | `FPC_COOKIE_HARD_DENY_PREFIXES` + `fpc_cookie_bypass` |
| Request | Operator-listed session cookies bypass (`private_cookies` or `bypass.cookies`) | `[full_page_cache]` / `[full_page_cache.bypass]` |
| Response | `Set-Cookie`, `Cache-Control: private`/`no-store`/`no-cache`, non-allowlisted `Vary`, streaming, hop-by-hop → never stored | `fpc_assess_store` |
| TTL | `max_ttl_seconds + stale_if_error_secs ≤ 43200` (12 h); recommended `≤ 21600` (6 h) | `[full_page_cache]` + EXY-LINT-0007 |

### Why the anonymous nonce is safe to share

WordPress builds nonces as `hash(tick | action | uid | session_token)`:

- A logged-out visitor has `uid = 0` and an empty session token, so **every anonymous visitor gets the same nonce within a tick**.
- `wp_nonce_tick()` uses `DAY_IN_SECONDS / 2` = **12 h**; `wp_verify_nonce()` accepts the current and previous tick, so a nonce lives **12–24 h**.
- A page cached at time `t` and served until `t + window` is safe while `window < 12 h`. The 12 h cap leaves the full tick of validity; 6 h is the recommended margin.
- `stale-if-error` extends the serve window, so it is part of the sum.

A nonce generated by WordPress for a logged-in user is tied to that user's session token; those requests never reach the shared cache (first row of the table).

### Per-session nonces from plugins

Plugins that mint nonces tied to their own anonymous session cookie must list that cookie in `[full_page_cache] private_cookies` (or `[full_page_cache.bypass] cookies`). Responses that set the cookie are already rejected, but later pages may not repeat `Set-Cookie`; the cookie list is the durable guard.

## Lint

`EXY-LINT-0007` (warning) fires when FPC is enabled and `max_ttl_seconds + stale_if_error_secs > 43200`. It does not change runtime behavior.

## Verification (2026-10-27)

Image `exyonq-wordpress:0.8.0-arm64`, WordPress 7.1.3, FPC enabled (`default_ttl_seconds = 300`, `max_ttl_seconds = 3600`), `[full_page_cache.key] query = ["p"]` for the plain-permalink test page.

| Check | Result |
| --- | --- |
| Anonymous `GET /?p=1` (cold) | `X-Cache: miss` |
| Anonymous `GET /?p=1` (warm) | `X-Cache: hit`, byte-identical body |
| Nonce in cached page | `2021810822`, served unchanged on HIT |
| `POST /wp-admin/admin-post.php` with that nonce from a **different** anonymous client (no cookies) | `200 OL02 nonce OK` |
| Logged-in `GET /?p=1` (`wordpress_logged_in_*`) | `X-Cache: bypass`, `X-Cache-Reason: cookie_denied`, different nonce (`430270bf5f`) |
| Cold page with `Set-Cookie` | never stored (covered by `fcgi_set_cookie_never_stored`) |

## Non-goals

- ESI `include` tags, per-fragment TTL, fragment cache namespaces.
- Response body rewriting / hole punching.
- Caching logged-in or per-session pages.
- Changing FPC keying or the store gate.

## Consequences

- Anonymous WordPress pages with nonces stay cacheable; no ESI parser or subrequest machinery.
- Sites that need per-fragment TTL must use a plugin-side AJAX/REST fragment or wait for a future ESI ADR.
- `EXY-LINT-0007` makes the TTL invariant visible at `config lint --warn`.
