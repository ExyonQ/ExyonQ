# K0.4 Core Smoke Matrix

Operational smoke for kernel readiness (not official benchmark, no performance claims).

## Run

```bash
cargo build -p exyonq -p exyonqctl
bash scripts/smoke/k0-core-smoke-matrix.sh
```

**Authoritative sendfile + `/metrics` wire scrape:** Linux host or CI (Darwin uses Mach-O binary; epoll/sendfile wire handlers are `#[cfg(target_os = "linux")]`).

## Matrix

| ID | Scenario | Criteria |
|----|----------|----------|
| S1 | `GET /site/1k.bin` | 200, 1024 bytes, sendfile not engaged |
| S2 | `GET /site/64k.bin` | 200, 65536 bytes, sendfile engaged if flags+Linux |
| S3 | `GET /site/1m.bin` | 200, 1048576 bytes, sendfile engaged if flags+Linux |
| S4 | `HEAD` static | 200, correct Content-Length |
| S5 | Wire static | Raw `GET /site/{1k,64k,1m}.bin` |
| S6 | `GET /api/*` | 200, upstream body |
| S7 | Proxy `HEAD` | 200 |
| S8 | Wire proxy | Raw `GET /api/*` |
| S9 | `/health` | 200 |
| S10 | `/metrics` | 200, sendfile counters present (Linux wire path) |
| S11 | `/unknown` | 404 |
| S12 | Upstream down | Controlled 502 |
| S13 | Reload invalid config | fail-closed (generation unchanged, server live) |
| S14 | Counters | `error`, `fallback`, `terminal_503`, `unknown_fd` stable on happy path |

## Counters (Prometheus)

- `exyonq_epoll_sendfile_complete_total`
- `exyonq_epoll_sendfile_error_total`
- `exyonq_epoll_sendfile_fallback_total`
- `exyonq_epoll_sendfile_terminal_503_total`
- `exyonq_epoll_sendfile_unknown_fd_event_total`

## Hot-path freeze

If smoke fails and fix requires `static_conn`, `epoll_sendfile`, or `site_static` preload/wire — stop and request authorization.
