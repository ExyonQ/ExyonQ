# Compatibility layer

Offline migration tools only. ExyonQ **never** reads Apache/NGINX/IIS config at runtime.

Importers live under `compat/` and are invoked via `exyonq-compat migrate` (Fase 4).

Scope is frozen in [`docs/compat/compatibility-scope-v1.md`](../docs/compat/compatibility-scope-v1.md).
